Security & undetectability

Undetectability
Exclude Veil from screen shares and recordings, and hide it from the taskbar.
How it works. Veil uses your OS's native capture-exclusion (NSWindowSharingNone on macOS, WDA_EXCLUDEFROMCAPTURE on Windows 10 2004+). This is best-effort: some capture paths (e.g. Zoom "without window filtering", or macOS 15.4+ in certain modes) may still see the window. On Linux, capture exclusion depends on the compositor.
API keys. Keys are encrypted at rest with your OS keychain and stored only on this device. Veil has no servers and sends no telemetry — requests go directly to your chosen provider.
